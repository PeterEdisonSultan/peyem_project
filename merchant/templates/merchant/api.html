Guide d'Intégration
Déclencher le Paiement

Copiez cette partie et mettez-la dans votre fonction de panier (là où vous validez la commande) : 

function validerCommande() {
    const MA_CLE = "{{ merchant.api_key }}";
    let total = calculerTotalPanier(); 
    let description = "Commande Sport 509";
    
    // APPEL AU SYSTÈME DE PAIEMENT
    if (typeof Peyem !== 'undefined') {
        Peyem.initiate(MA_CLE, total, description);
    } else {
        alert("Erreur : Le script PEYEM n'est pas chargé.");
    }
}

Insérez ceci dans votre page de confirmation, après avoir calculé le total en PHP : 

<script>
  const MA_CLE = "{{ merchant.api_key }}";
  const montantTotal = <?php echo $total; ?>;
  
  function payer() {
      if (typeof Peyem !== 'undefined') {
          Peyem.initiate(MA_CLE, montantTotal, "Commande PHP");
      } else {
          alert("Erreur : Le script PEYEM n'est pas chargé.");
      }
  }
</script>

Utilisez ceci pour un bouton d'achat rapide sur une page unique : 

<button onclick="payer()">Payer 1000 HTG</button>
